# 🇮🇱 Israeli Energy Infrastructure Map

Interactive map of Israel's power plants + electrical substations.

## Files

| File | Size | Description |
|------|------|-------------|
| `index.html` | 24 KB | Standalone map - open in browser |
| `data/israel_power_plants.csv` | 20 KB | 59 power plants (WRI subset) |
| `data/global_power_plants_wri.csv` | 11 MB | Full WRI database (35K plants) |
| `data/planning-intelligence.md` | 170 KB | Planning knowledge base |

## Quick Start

```
open index.html
```
